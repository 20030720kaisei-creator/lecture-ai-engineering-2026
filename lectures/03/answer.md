    """

## 宿題

- 取り組んだレベル：基礎
- やったこと：
    - `app/agent.py` の `INSTRUCTIONS` を変更し、「第N回を復習したい」という依頼では `make_quiz` を使い、講義の要点を明示的に尋ねられた場合は `get_lecture_summary` を使うようにした。
    - 変更前後で `uv run python -m app.agent --trace "第2回を復習したい"` を実行して比較した。
- 結果：変更前は `get_lecture_summary({'lecture': 2})` が呼ばれ、第2回の要点が返った。変更後は `make_quiz({'lecture': 2})` が呼ばれ、LoRAの意味を問う問題が出た。答えは利用者が回答するまで表示されなかった。
- 気づき・疑問：ツールのdocstringだけでなく、`INSTRUCTIONS` にツールを選ぶ条件と優先順位を書くことで、曖昧な「復習したい」という依頼でも意図したツールを選びやすくなった。
